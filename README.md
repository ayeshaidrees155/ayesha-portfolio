# 🌟 Ayesha Idrees - Personal Portfolio

A clean, modern, and fully responsive personal portfolio web application built to showcase my journey as a Software Engineering student and Frontend and React.js Developer. It features a custom drawer splash screen, interactive UI components, and direct links to my live web projects.

---

## 🚀 Live Demo

## 🔗 **[View Live Portfolio](https://ayeshaidrees-portfolio.vercel.app/)**

## 🛠️ Tech Stack

- **Core:** React.js, JavaScript (ES6+)
- **Styling:** Tailwind CSS, Material UI (MUI)
- **Build Tool:** Vite
- **Deployment:** Vercel

Here are the projects currently showcased in my portfolio:

4. **Interactive Calculator**
   - _Description:_ A sleek and responsive calculator web application designed for seamless mathematical computations, featuring clean DOM event handling and an intuitive user interface.

   - _Live Link:_ [View Project](https://ayesha-calculator.vercel.app)
